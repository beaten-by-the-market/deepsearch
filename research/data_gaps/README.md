# DeepSearch로 받을 수 없는 시장 데이터 (CHECK API 시나리오 대조)

## 결론

- **종목별 투자자 수급, 공매도, 대차, 신용, 프로그램매매, 지수선물, ETF NAV, 장중 시세(분봉·틱·호가), NXT, 대량매매 데이터는 이 구독의 DeepSearch에 없다.** 레퍼런스 문서에 관련 단어가 하나도 없다. 자연어 질의 16개는 모두 데이터로 해석되지 않고 기업 개요 표로 빠졌다. `GetStockPrices`가 허용하는 15개 컬럼에도 없다.
- 그래서 CHECK API 케이스 시나리오 42개 중 **14개는 DeepSearch로 구현할 수 없다**: 대차잔고, 신용융자, 수급 주도주, 종목 수급 추이, 공매도 데일리, 선물 미결제·베이시스, 프로그램매매, ETF 괴리율, 국고채 금리곡선, 그리고 시장미시구조 5개.
- **한국은행 시리즈에는 시장 전체 합계가 일부 있지만 2024년 3~4월에서 멈춰 있다.** 신용융자 잔고, 투자자별 주식거래, 지수선물 거래, 국고채 금리, 외국인 순매수(시장 전체)가 해당한다. 오류 없이 빈 결과가 오므로 날짜를 꼭 확인해야 한다.
- **수치는 없어도 사건은 문서로 잡힌다.** 공매도 과열종목 지정, 투자경고 같은 시장경보는 거래소 공시로 검색된다. 블록딜과 신용융자 잔고는 뉴스 기사로만 찾을 수 있다.

검증일 2026-11-25 · 대상: compute 자연어 쿼리, `GetStockPrices`, `GetMarketIndexSymbols`, `QueryBankOfKoreaSeriesInfo`, `DocumentSearch`, `GetBondYields`, `FindEntity("DataSeries", …)` · 재현 스크립트: [verify_data_gaps.py](verify_data_gaps.py)

## 질문

KOSCOM CHECK API용으로 정리한 분석 시나리오 42개가 있다. 별도 레포 `check-api-krx-dl`의 `케이스시나리오/` 폴더(6개 유형)다. 이 시나리오들을 DeepSearch로 옮길 수 있는지 분류했더니 14개가 불가로 나왔다.

1. 그 14개 리포트는 원래 어떤 원데이터를 쓰는가?
2. DeepSearch에 정말 그 데이터가 없는가? 다른 이름이나 다른 함수로 들어 있지는 않은가?

## 방법

CHECK API는 호출하지 않았다. 원데이터는 시나리오 문서의 "뒤에서 쓰는 데이터" 절과 스킬 스크립트(`short_daily.py`)에서 읽었다. DeepSearch 쪽은 다음 순서로 확인했다.

1. **문서.** `docs/reference/` 전체(공식 가이드 원문 포함)와 `skills/deepsearch/`에서 대차·신용융자·신용잔고·공매도·short·loan·margin·credit을 검색했다.
2. **자연어 질의.** "삼성전자 {용어} 2026-11-01-2026-11-24" 형식으로 16개 용어를 넣었다. 대조군은 "거래량"이다. 결과에 `ceo`·`business_rid`처럼 기업 개요 표에만 있는 컬럼이 나오면, 질의가 데이터로 해석되지 않은 것으로 판정했다.
3. **`GetStockPrices` 컬럼.** 없는 컬럼을 넣으면 오류 메시지에 허용 컬럼 목록이 나온다. 그 목록을 받았다.
4. **한국은행 시리즈.** 증시 관련 통계표 5개의 항목과 마지막 시점을 `QueryBankOfKoreaSeriesInfo`로 받았다.
5. **사건 문서.** 공매도 과열 지정, 시장경보, 블록딜, 신용융자 잔고를 공시와 뉴스에서 검색했다.
6. **기타.** 지수 목록에 선물이 있는지, 채권 함수가 되는지, 시리즈 검색 함수로 찾을 수 있는지 봤다.

### 2. 자연어 질의

대조군 "거래량"만 `date, symbol, entity_name, 거래량 …` 4개 컬럼으로 정상 해석됐다. 나머지 16개는 모두 기업 개요 표(29개 컬럼)로 빠졌다. 오류는 나지 않는다.

### 6. 기타

- `GetMarketIndexSymbols()`: 코스피, 코스피 대형·중형·소형주, 코스피 200·100·50, 코스닥, 코스닥 대형·중형·소형주. 11종 모두 현물지수이고 선물·섹터지수는 없다.
- `GetBondYields`: `NameError: UFunction 'GetBondYields' is not defined`. 채권 함수 18개가 모두 같다([MASTER §16](../../docs/reference/DEEPSEARCH_API_MASTER.md#16-현재-구독으로-쓸-수-없는-api)).
- `FindEntity("DataSeries", …)`: 대조군 "실업률"까지 모든 키워드가 0행이다. 이 함수로는 시리즈를 찾을 수 없다.

원자료: [data/other_probes.csv](data/other_probes.csv)

## 실무 영향

- 위 데이터가 필요한 요청을 받으면 DeepSearch로 근사하지 말고 **"DeepSearch에서는 받을 수 없다"고 먼저 말한다.** 자연어 질의가 오류 없이 기업 개요 표를 돌려주므로, 결과를 확인하지 않으면 데이터가 온 것으로 착각하기 쉽다.
- 한국은행 시리즈는 기간을 주지 않거나 최근 기간만 주면 빈 결과나 2024년 값이 온다. 국고채 금리, 시장 수급, 신용융자를 "현재 값"으로 쓰면 안 된다.
- 바꿔 쓸 수 있는 것:
  - 공매도 과열 지정, 시장경보: 공시 검색으로 지정일을 잡는다. 그 전후의 주가·거래량 반응은 `GetStockPrices`로 본다.
  - 블록딜, 신용융자: 뉴스 검색으로 보도와 기사 속 수치를 찾는다. 구조화된 데이터는 아니다.
  - 미국 금리·환율·유가: FRED(`QueryFredSeriesData`)는 최신값이 나온다. 다우·나스닥·브렌트유도 있다.
- 다른 소스가 필요하다: CHECK API(등록 IP), KRX 정보데이터시스템, 한국은행 ECOS 직접 조회, 금융투자협회 통계. 이 노트에서는 이 소스들을 검증하지 않았다.

## 한계·미확인

- **DeepSearch 자체 수집 지표(`DS:`)는 ID를 알아야 조회된다.** 시리즈 검색 함수가 동작하지 않아서, 그 안에 공매도·신용 지표가 없다는 것까지는 증명하지 못했다.
- **v2 REST API**(`api-v2.deepsearch.com`, 215개 경로: 시장·ETF 등)는 이 키로 401이라 확인하지 못했다. 상위 구독에는 일부가 있을 수 있다.
- `after_market_*` 컬럼의 정의(시간외 단일가인지 등)는 확인하지 못했다.
- 자연어 질의는 용어 16개만 시험했다. 다른 표현이 데이터로 해석될 가능성을 완전히 배제하지는 못한다. 다만 공식 가이드의 시장데이터 항목 목록(시가총액·시가·…·PER·PBR·배당수익률)에도 이 데이터들은 없다.

## 재현 방법

```bash
python research/data_gaps/verify_data_gaps.py            # 기준일 2026-11-24
python research/data_gaps/verify_data_gaps.py 2026-12-31  # 다른 기준일
```

키는 레포 루트 `.env`의 `API_KEY`다. 원시 응답은 `data/cache/`에 캐시되고 git에서 제외된다. 사건 문서 검색은 캐시하지 않는다.
