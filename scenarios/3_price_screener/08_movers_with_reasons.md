# 3-08 오늘 급등락 종목과 이유 — 공시 + 뉴스 제목·긍부정

[노트북](08_movers_with_reasons.ipynb) · [Colab에서 열기](https://colab.research.google.com/github/beaten-by-the-market/deepsearch/blob/main/scenarios/3_price_screener/08_movers_with_reasons.ipynb) · CHECK 원본: `3_시세스크리너/01_오늘급등락거래대금` · 구분: **확장**

## 한 줄 요약
그날 등락률 상위·하위와 거래대금 상위 종목을 뽑고, 각 종목에 전날 장 마감 후부터 당일까지의 **공시와 뉴스(제목·긍부정)**를 붙여 왜 움직였는지 보여줍니다.

## 이렇게 물어보세요
- "오늘 많이 오른/내린 종목 뭐야? 왜 그런지도 알려줘"
- "오늘 거래대금 상위 종목은 무슨 뉴스 때문이야?"
- "11월 24일 급등주 이유 정리해줘" → `ASOF`만 바꾸면 과거 날짜도 됩니다

## 왜 DeepSearch로 하나
| 항목 | CHECK 원본 | DeepSearch |
|---|---|---|
| 원인 설명 | 공시만 (뉴스에 종목 태그 없음) | 공시 + **종목 태그된 뉴스 제목·긍부정** |
| 날짜 | 순위 데이터가 최신 거래일만 | 전 종목 하루치를 날짜로 받아 **과거 날짜도** |
| 공시 범위 | 당일 | 전날 15:30 이후 ~ 당일 (장 마감 후 공시까지) |

## 결과 예시 (2026-11-24, 상승 2,140 / 하락 426 / 상한가 11)
**상승 상위**
| 종목 | 등락률 | 원인 근거 | 공시·뉴스 |
|---|---|---|---|
| 휴림로봇 | +29.9% | 공시+뉴스 | 투자경고 지정예고, 공매도 과열 / "엔비디아·삼전發 훈풍에 로봇주 '불기둥'…휴림로봇 이틀째 '上'" |
| 현대오토에버 | +29.9% | 뉴스 | "젠슨황 복귀에 '깐부주' 부활…현대오토에버 상한가" (긍정 5) |
| KH바텍 | +30.0% | 뉴스 | "'폴더블폰 힌지' KH바텍, 젠슨 황 복귀 훈풍에 '上'" |
| 모베이스전자 | +30.0% | 없음 | — |

**거래대금 상위**: SK하이닉스 3.9조(+6.7%), 삼성전자 3.0조(+6.7%), 삼성전기 6,675억(+10.3%) — 공시 없이 임원 인사·AI 수혜 기사.

**원인 근거 집계** (그룹별 8종목)
| | 상승 상위 | 하락 상위 | 거래대금 상위 |
|---|---|---|---|
| 공시+뉴스 | 3 | 1 | 1 |
| 뉴스만 | 2 | 0 | 3 |
| 공시만 | 0 | 2 | 1 |
| 없음 | 3 | 5 | 3 |

뉴스만으로 설명된 종목(상승 2, 거래대금 3)은 CHECK 원본에서는 '이유 없음'으로 남았을 종목입니다.

## 결과 읽는 법
- **공시 없이 뉴스만 있는 급등**은 테마·업황 기사로 움직인 경우가 많습니다. 이날은 "젠슨 황 복귀", "로봇주" 기사가 여러 상한가 종목에 공통으로 붙었습니다.
- 하락 상위에는 유상증자 정정, 소수계좌 거래집중 같은 **공시 쪽 원인**이 더 많았습니다.

## 주의·한계
- **뉴스가 0건인 급등주도 있습니다.** 로보티즈(+19.5%, 거래대금 2,090억)는 그날 태그된 기사가 0건이었습니다. 수집되지 않았거나 태그가 빠진 경우라, 태그 검색이 0건이면 제목 검색을 한 번 더 합니다.
- 뉴스 종목 태그에 동명 오탐이 있습니다('DB'는 연예 기사까지 태그됨). 제목에 종목명이 든 기사를 우선 보여줍니다.
- 긍부정은 기사 단위 모델 값이고(`polarity`, 없으면 `customized_ml`), 사진 기사는 뺍니다.
- 등락률·거래대금은 KRX 기준(NXT 미포함), 가격은 수정주가입니다. 상장 당일 종목은 제외합니다.

## 쓰는 DeepSearch 함수
`GetStockPrices`(전 종목 하루치), `GetStockSymbols`, `GetMarketIndexes`(직전 거래일), `DocumentSearch(["company"],["disclosure"], …)`(묶음 1회), `DocumentSearch(["news"], …)`(종목별 약 24회)
