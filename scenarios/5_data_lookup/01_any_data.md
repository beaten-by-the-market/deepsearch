## 한 줄 요약
"그냥 데이터 좀 줘" 요청을 받는 기본 노트북입니다. 종목 일별 시세, 여러 종목 비교, 지수, 거래대금 순위, PER·PBR·배당수익률, 분기 실적을 표로 뽑고 CSV로 저장합니다.

## 이렇게 물어보세요
- "삼성전자 최근 한 달 일별 시세랑 거래량 뽑아줘"
- "코스피 거래대금 상위 20종목 알려줘 (ETF 빼고)"
- "반도체 3사 종가 나란히 표로"
- "삼성전자 PER·PBR 추이", "PER 낮은 대형주"
- "삼성전자 최근 분기 실적", "CSV로 저장해줘"

## CHECK 원본과 달라진 점
| 항목 | CHECK | DeepSearch |
|---|---|---|
| 일별 시세·거래량·시총, 지수, 순위 | 있음 | 있음 (순위는 전 종목 하루치 한 번 받아 정렬) |
| PER·PBR·배당수익률 | 일별 필드 없음(컨센서스 기반만) | **자연어 질의로 일별 제공**, 전 종목 PER도 한 번에 |
| 분기·연간 재무 | IFRS 데이터 | `GetFinancialStatements` |
| 외국인 보유율·투자자 수급·선물·ETF NAV·국고채 | 있음 | **없음** |

## 결과 예시 (2026-11-24, 노트북 실행값)
| 항목 | 값 |
|---|---|
| 삼성전자 종가 | 189,400원 (+6.70%), 거래대금 3.0조 |
| 삼성전자 PER / PBR / 배당수익률 | 28.68 / 2.96 / 0.94% |
| 코스피 거래대금 1위 (ETF 제외) | SK하이닉스 3.9조 — ETF 포함 시 KODEX 200(1.7조)이 3위 |
| PER 최저 대형주(시총 1조↑, 보통주) | KCC 1.67, 맥쿼리인프라 2.35, 다우기술 2.55 |
| 삼성전자 2026년 3분기 | 매출 195.25조 · 영업이익 107.44조 · 영업이익률 55.0% |

## 결과 읽는 법
- 순위는 기본으로 ETF·ETN을 뺍니다. 넣으면 레버리지·인버스 ETF가 상위를 차지합니다.
- PER이 아주 낮은 종목은 일회성 이익 때문일 수 있습니다. 재무 표로 확인하세요.
- PER·PBR의 FY N 실적은 N+1년 첫 거래일부터 쓰입니다(look-ahead, [research/pbr_bps](../../research/pbr_bps/README.md)).

## 주의·한계
- 주가는 수정주가이고, 거래량·거래대금·시가총액은 당일 실제 값입니다(KRX 기준, NXT 미포함).
- 자연어 질의 결과의 컬럼 이름에 질의 문구가 붙어 나와(`PER 2026-11-18-2026-11-24`) 노트북에서 정리합니다.
- 외국인보유비율 같은 없는 지표는 오류 없이 **기업 개요 표**가 돌아옵니다. 노트북 마지막 셀처럼 컬럼을 확인하세요.

## 쓰는 DeepSearch 함수
`GetStockPrices`, `GetMarketIndexes`, `GetStockSymbols`, compute 자연어 질의(PER·PBR·배당수익률), `GetFinancialStatements`
