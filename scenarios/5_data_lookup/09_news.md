# 5-09 뉴스정보 가져오기 — 키워드·섹션·언론사·시간대·종목으로 뉴스 모으기

[노트북](09_news.ipynb) · [Colab에서 열기](https://colab.research.google.com/github/beaten-by-the-market/deepsearch/blob/main/scenarios/5_data_lookup/09_news.ipynb) · 앱에서 하던 일: 언론사 묶음·뉴스 섹션·날짜(또는 날짜+시간) 조건으로 뉴스를 검색하고 모든 페이지를 받던 부분 · 구분: **기본(데이터 가져오기)**

## 한 줄 요약
`news_search()` 함수 하나로 키워드·섹션·언론사 묶음·시간 범위·종목 조건을 조합해 뉴스를 받습니다. 한 페이지 100건과 검색 기간 1년 제한은 함수가 알아서 나눠 받습니다.

## 이렇게 물어보세요
- "이번 주 경제지 기사 중 HBM 기사 다 모아줘"
- "오늘 오전 9~12시 삼성전자 기사 뽑아줘"
- "SK하이닉스가 주제인 기사 1년 넘게 모아서 CSV로 줘"

## 결과 예시 (기준일 2026-11-24, 노트북 실행값)
| 예시 | 결과 |
|---|---|
| 경제 섹션 × 중앙경제지 × 'HBM' (1주) | 169건 전부. 서울경제 37 · 이데일리 34 · 한국경제 25 |
| '삼성전자', 11-24 09:00~12:00 | 298건 중 258건(3페이지). 시각 범위 09:00~12:00 확인 |
| SK하이닉스 주제 기사 13개월 | 1년 + 1개월 두 구간으로 나눠 받음(전체 27,522 + 2,701건, 예시라 구간마다 1페이지만) |
| 1주 경제 기사 많은 언론사 | 연합뉴스 3,395 · 뉴시스 2,803 · 뉴스1 2,353 |
| 언론사 목록 | DeepSearch 574곳 · 빅카인즈와 둘 다 45곳 · 딥서치만 529곳 |

## Colab으로 하면
- 셀 순서: 섹션·언론사 묶음 사전 → `news_search()` → 예시 4개 → 언론사 집계·목록 → CSV 저장.
- 조건은 함수 인자로 바꿉니다.
  - `keyword`, `section`("경제" 등)
  - `publishers`: 묶음 이름이나 언론사 이름 목록
  - `date_from`/`date_to`, 시각까지 자를 때는 `time_from`/`time_to`
  - `stock`(6자리 코드), `max_pages`
- 언론사 목록 파일은 레포 `scenarios/_data/`에서 읽습니다. Colab에서는 GitHub raw 주소로 읽습니다.
- 한계: 수만 건을 받으면 오래 걸리고 세션이 끊길 수 있습니다. 건수만 필요하면 `DocumentTrends`·`DocumentAggregation`을 쓰세요.

## 웹앱으로 만든다면
- **검색 조건 영역**(접었다 펴는 칸): 언론사 묶음 선택 + 개별 언론사 추가(다중 선택), 뉴스 섹션, 날짜 또는 날짜+시간 범위, 키워드를 둡니다.
- **검색 버튼:** 누르면 첫 페이지의 `total_matches`로 전체 페이지 수를 구하고, 진행 표시줄(`st.progress`)과 함께 나머지 페이지를 받습니다. 기간이 1년을 넘으면 구간별로 나눕니다.
- **결과:** 세션 상태에 보관하고 표(시각·언론사·제목·종목·긍부정·링크)와 CSV 다운로드 버튼으로 보여 줍니다. 이후 "상장사 거르기(2-13)", "종목 한 장 보기(2-14)" 화면이 이 결과를 이어 씁니다.
- 언론사 목록·묶음은 설정 파일로 빼 두고, 같은 조건의 반복 검색은 짧게(예: 10분) 캐시합니다.

## 주의·한계
- 한 페이지가 100건보다 적게 오는 일이 흔합니다(80~90건). 그래도 뒤에 결과가 더 있으므로 **전체 건수에 닿을 때까지** 넘겨야 합니다. 노트북의 `doc_pages()`가 그렇게 합니다.
- `securities.symbol:6자리`는 그 종목이 **주제인** 기사입니다. 동명 오인식 기사가 섞입니다(예: SK하이닉스 조회에 무관한 정치 기사가 섞임).
- 긍부정은 기사 절반가량에만 원래 값이 있고, 나머지는 DeepSearch 보조 모델 값입니다.
- 언론사 집계는 `publisher:N`으로 합니다(`publisher.raw:N` 집계는 서버 오류).

## 쓰는 DeepSearch 함수
`DocumentSearch`, `DocumentTrends`, `DocumentAggregation`
