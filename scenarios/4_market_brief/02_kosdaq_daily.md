## 한 줄 요약
코스닥 하루를 지수·대중소형·시가총액·종목동향·업종별 등락·상승/하락/거래대금 상위 종목으로 정리합니다. 업종 등락률은 종목 업종코드로 직접 계산합니다.

## 이렇게 물어보세요
- "코스닥 어제 하루 어땠어?"
- "11월 24일 코스닥 상승/하락 종목수랑 업종동향 보여줘"
- "코스닥에서 오늘 많이 오른 종목이랑 업종 알려줘"

## CHECK 원본과 달라진 점
| 항목 | CHECK | DeepSearch |
|---|---|---|
| 지수·시총·종목동향 | 거래소 데이터 | 지수 + 전 종목 하루치로 집계 |
| 업종동향 | 코스닥 업종지수 | **업종코드(KSIC 중분류)별 시총가중 등락률로 근사** |
| 상승·하락·거래대금 상위 | — | 추가 |
| 투자자별 순매수, 공매도, 신용잔고 | 있음 | **없음** |

## 결과 예시 (2026-11-24, 노트북 실행값)
| 항목 | 값 |
|---|---|
| 코스닥 지수 | 665.88 (+4.79%) · 대형주 +5.81% · 중형주 +4.37% · 소형주 +2.84% |
| 시가총액 / 거래대금(지수) | 381.4조 / 5.9조 |
| 종목동향 | 상승 1,389 · 하락 322 · 보합 39 · 상한가(근사) 10 · 하한가 0 |
| 강한 업종 | 자동차·부품 +10.61%, 전기장비 +9.82% |
| 약한 업종 | 방송 −1.67%, 섬유제품 −0.71% |
| 거래대금 1위 | 원익홀딩스 3,446억 (−2.18%) |

## 결과 읽는 법
- 대형주(+5.8%)가 소형주(+2.8%)보다 강하면 큰 종목 중심의 반등입니다.
- 업종 표의 "대표 종목"이 업종 등락을 끌고 갔는지 보세요. 종목 수가 적은 업종은 한두 종목이 좌우합니다(5개 미만은 표에서 뺌).

## 주의·한계
- 업종 분류는 표준산업분류(KSIC)라 거래소 업종과 다릅니다. 지주회사는 따로 묶었습니다.
- 상한가·하한가는 ±29.5~30.5% 근사입니다. ±30%를 넘는 종목은 따로 표시합니다(11-24 엠비디 −39.57%는 상장 첫날).
- 투자자별 수급·공매도·신용잔고는 DeepSearch에 없습니다([research/data_gaps](../../research/data_gaps/README.md)).
