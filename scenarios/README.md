# scenarios — DeepSearch 분석 시나리오 노트북 (Colab)

KOSCOM CHECK API용으로 만든 분석 시나리오(별도 레포 `check-api-krx-dl`의 `케이스시나리오/`)를 **DeepSearch API만으로** 다시 만든 노트북 모음입니다.
- **각색:** CHECK에 있던 시나리오를 DeepSearch로 옮기면서 없는 데이터를 대신할 방법을 넣었습니다.
- **확장:** DeepSearch에만 있는 데이터를 쓰는 새 시나리오입니다. 증권사 목표주가·투자의견, 뉴스 종목 태그·감성, 리포트, 토픽, 기업집단, 사업보고서 검색 등이 해당합니다.
- **기본(데이터 가져오기):** 종목정보·뉴스·공시·IR·리포트·특허를 가져오는 기본 노트북입니다(5-08~13). 예전 뉴스 스크랩 웹앱의 기능을 단위별로 나눠 옮긴 것입니다.

모든 노트북은 실제로 실행한 결과(표·그림)를 담고 있습니다. 기준일은 2026-11-24입니다.

## 쓰는 법 (Colab)
1. 아래 표에서 노트북을 열고 맨 위 **Colab에서 열기** 배지를 누릅니다.
2. Colab 왼쪽 🔑(Secrets)에 이름 `DEEPSEARCH_API_KEY`로 키를 넣고 "노트북 액세스"를 켭니다. 키는 `아이디:비밀번호` 형식이든 base64 문자열이든 됩니다.
3. 위에서부터 실행합니다. 셀 위쪽의 `ASOF`(기준일)·종목·키워드를 바꿔 다시 돌리면 됩니다.

로컬에서는 레포 루트 `.env`의 `API_KEY`를 읽습니다.

## 웹앱으로 묶는다면
노트북은 Colab에서 하나씩 돌리는 형태입니다. 같은 함수를 웹앱(예: Streamlit)으로 묶으면 화면은 이렇게 나뉩니다. 각 시나리오 문서의 "웹앱으로 만든다면" 절에 화면별 구성이 더 자세히 있습니다.
- **공통 모듈 — 5-08 종목정보:** 상장사 목록과 식별자 지도를 하루 1회 캐시합니다. 종목 선택·자동완성과 문서-상장사 매칭에 씁니다.
- **검색 화면 — 5-09~5-13:** 뉴스·공시·IR·리포트·특허가 카테고리 탭이 됩니다. 페이지를 넘기며 진행 표시와 함께 받아 세션에 보관합니다.
- **결과·필터 화면 — 2-13:** 받은 결과에만 시장·종목·관심종목(엑셀 업로드)·이슈 카테고리 필터를 걸고 종목별 막대그래프와 CSV 다운로드를 붙입니다. API를 다시 부르지 않습니다.
- **종목 상세 화면 — 2-14:** 요약 카드, 52주 주가와 공시·IR 날짜 표시, 뉴스·공시·IR·리포트 탭을 둡니다. 2-13에서 종목을 누르면 넘어옵니다.
- **분석 화면:** 1·3·4번 유형(실적·컨센서스, 스크리너, 시황)은 별도 페이지로 붙입니다.
- **공통:** 키는 `st.secrets`에 둡니다. 반복 검색은 10~30분 캐시하고, 언론사·이슈 묶음은 설정 파일로 뺍니다. DB 없이 동작합니다.

- **DeepSearch로 불가 (14개):** 대차잔고, 신용융자, 수급 주도주, 종목 수급 추이, 공매도 데일리, 선물 미결제·베이시스, 프로그램매매, ETF 괴리율, 국고채 금리곡선, 그리고 시장미시구조 5개. 원데이터와 근거는 [research/data_gaps](../research/data_gaps/README.md)에 있습니다.
- **각색:** 위 표의 "각색" 항목입니다.
- **그대로 옮길 수 있지만 아직 노트북이 없는 것:** 1-02 추정치 리비전, 1-04 피어 밸류에이션, 1-06 지분구조, 1-07 재무 트렌드, 2-02 시장경보 효과, 2-04 공시 흐름 집계, 2-07 뉴스·공시 결합, 3-02 기간 급등·급락. 다른 노트북이 내용을 포함하는 것: 1-02는 1-08·1-11, 3-01은 3-08, 3-05는 3-10, 2-06은 2-10이 담고 있습니다.

## 공통 주의
- **주가:** 수정주가입니다(분할·증자 소급 반영, 배당 미반영). 거래량·거래대금·시가총액은 당일 실제 값이고 KRX 기준입니다(NXT 미포함).
- **수급·공매도·장중 데이터:** 투자자별 수급, 공매도·대차·신용, 지수선물, ETF NAV, 장중 데이터는 DeepSearch에 없습니다.
- **한국은행 시리즈:** 2024-04에 멈춰 있습니다. 미국·글로벌 거시는 FRED를 씁니다.
- **문서 검색의 종목 지정:** `securities.symbol:005930`(접두어 없는 6자리)을 씁니다.
- **거래소 공시:** 공매도 과열·투자경고 같은 거래소 공시는 2026-08부터 촘촘하게 들어 있습니다.
- **컨센서스:** 대형주도 증권사 3~7곳뿐입니다. 입력 오류(10배 값, 매출을 영업이익 칸에 넣은 값)가 있어 노트북은 중앙값의 1/3~3배를 벗어난 값을 빼고 계산합니다.

## 고치는 법 (개발자용)
- **원본:** `_src/<유형>/<이름>.py`에 있습니다. `# %%`로 셀을 나눕니다.
- **빌드:** `python scenarios/_tools/build.py <유형>/<번호>`를 실행하면 준비 셀(Colab 배지, 키 읽기, 공통 헬퍼)을 붙이고 실행해 `.ipynb`를 다시 만듭니다. `.ipynb`를 직접 고치지 마세요.
- **출력 확인:** `python scenarios/_tools/show.py <ipynb>`로 셀별 출력을 텍스트로 봅니다.
- **헬퍼:** `_tools/ds_helper.py`는 모든 노트북의 준비 셀에 그대로 들어갑니다. 고친 뒤에는 `python scenarios/_tools/build.py`로 전부 다시 빌드하고, 각 문서 "결과 예시"의 숫자가 바뀌지 않았는지 확인하세요.
- **실행 폴더:** 빌드는 `_tools/_run/`(git 제외)에서 실행되므로 노트북이 저장하는 CSV는 그곳에 쌓입니다.
- **자료:** `_data/`의 언론사 목록 등은 로컬에서는 레포 파일을, Colab에서는 GitHub raw 주소를 읽습니다(push 후 동작).
