# 토픽 인사이트

Topic Insight 관련 API

<!-- repo-memo:start -->
> **[레포 검증 메모 2026-11-25 — 공식 문서 아님]**
> - `{DEEPSEARCH_API_URL}` = `https://api.deepsearch.com`. compute와 같은 `Authorization: Basic {인증키}`로 동작합니다.
> - `topicId`는 `SearchTrendingTopics` 결과의 `uid`(또는 `uid_str`)입니다. 예: `GET https://api.deepsearch.com/v1/topic-insight/insight?type=trending&section=economy&topicId=176349687&stream=false` → `{"success": true, "data": "요약 텍스트..."}`. 없는 토픽이면 400 `topic not found`.

# Insight

토픽 관련해서 인사이트 생성 API

```
GET {DEEPSEARCH_API_URL}/v1/topic-insight/insight?type={type}&section={section}&topicId={topic_id}&stream={stream}
```

#### Parameter:

`type` : 토픽 type. One of  `trending` or `historical`

`section`: 토픽 섹션. One of:

* top
* economy
* world
* tech
* entertainment
* politics
* society
* culture
* sports

`topic_id`: 토픽 ID

`stream`: client에서 결과 stream 여부

**Examples**

```
/v1/topic-insight/insight?type=trending&section=top&topicId=150973073&stream=false
```

{% code fullWidth="true" %}

```
/v1/topic-insight/insight?type=historical&section=top&topicId=1313406091740188672&stream=true
```

# Question

토픽 관련해서 질문 생성 API

```
GET {DEEPSEARCH_API_URL}/v1/topic-insight/questions?type={type}&section={section}&topicId={topic_id}&stream={stream}
```

#### Parameter:

`type` : 토픽 type. One of  `trending` or `historical`

`section`: 토픽 섹션. One of:

* top
* economy
* world
* tech
* entertainment
* politics
* society
* culture
* sports

`topic_id`: 토픽 ID

`stream`: client에서 결과 stream 여부

**Examples**

```
/v1/topic-insight/questions?type=trending&section=top&topicId=150973073&stream=true
```

{% code fullWidth="true" %}

```
/v1/topic-insight/questions?type=historical&section=top&topicId=1313406091740188672&stream=false
```

{% endcode %}

#### Response

* `stream=True` response; `text/event-stream`

```
data: 1. 마약류와 향정신성의약품 처방 시 환자 투약내역 확인 의무화에 대한 법률 개정은 어떤 내용을 포함하고 있나요?
data: 2. 이번 법률 개정으로 인해 마약류 오남용 예방에 어떤 영향이 있을 것으로 예상되나요?
data: 3. 마약류 관리에 관한 법률 개정안이 국회 본회의를 통과하면서, 의료 분야에서의 마약류 오남용 문제가 해결될 수 있는 가능성이 높아졌다고 볼 수 있을까요?

data: [DONE]
```

* `stream=False`

```
{
    "success": true,
    "data": "1. 송중기의 칸 레드카펫 불참에 대한 이슈는 어떤 의미가 있을까요?\n2. 송중기의 생애 첫 칸 레드카펫 출연이 관심을 받은 이유는 무엇일까요?\n3. 영화 '화란'의 성공적인 상영과 송중기의 역할은 어떤 영향을 미칠 수 있을까요?"
```

# Answer

토픽 관련해서 질의응답 API

```
GET {DEEPSEARCH_API_URL}/v1/topic-insight/answer?type={type}&section={section}&topicId={topic_id}&question={question}&stream={stream}
```

#### Parameter:

`type` : 토픽 type. One of  `trending` or `historical`

`section`: 토픽 섹션. One of:

* top
* economy
* world
* tech
* entertainment
* politics
* society
* culture
* sports

`topic_id`: 토픽 ID

`question`: 토픽에게 답변 받고 싶은 질문&#x20;

`stream`: client에서 결과 stream 여부

**Examples**

```
/v1/topic-insight/answer?type=trending&section=top&topicId=150973073&question=1. 마약류·향정신성의약품 처방 내역 확인 의무화로 인한 변화가 환자 및 병원에 어떤 영향을 미칠까요?&stream=true
```
