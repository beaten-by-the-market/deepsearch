# DeepSearch Data Platform

## DeepSearch Data Platform

DeepSearch Data Platform 은 방대한 기업/산업/금융/경제/인물 데이터를 손쉽게 검색/연산/분석 할 수 있도록 API 형태로 제공합니다.&#x20;

뉴스,공시,금융기관이 발행하는 각종 보고서, 기업 재무 정보, 주식 시장 정보, 국가 통계 자료 등을 실시간으로 수집하고 있으며,서로 성격이 다른 이들 데이터를 대상으로 교차 계산이 가능하도록 지원합니다.

DeepSearch에서 말하는 계산이란, 단순 숫자들의 산술적인 계산이 아닌 보다 큰 범위의 계산을 의미합니다:

* 기본적인 사칙연산 및 수학 함수
* 기계학습 기반의 자연어 처리
* 기호연산(Symbol Computation)

&#x20;

# API 사용 방법

### **DeepSearch API**&#x20;

금융데이터에 대한 검색, 연산, 분석 기능을 모두 포함하고 있는 API 로, compute API 를 통하여 사용자가 다양한 형태의 검색 쿼리를 입력할 수 있으며, 그 쿼리에 따른 결과를 리턴합니다.

### API 호출 주소

<https://app-api.deepsearch.com>

( GET 방식과 POST 방식을 모두 지원하며, 파라미터가 많은 경우 POST 로 호출 )

### 사용방법

HTTPS 요청 시 HTTP 헤더에 다음 인증 키 추가\
Authorization: Basic {인증키}

### curl 예제

curl -H 'Authorization: Basic {인증키}' -XGET '<https://app-api.deepsearch.com/v1/compute?input={쿼리}>'

```
쿼리 예시
https://app-api.deepsearch.com/v1/compute?input=삼성전자 매출액

API 예시
https://app-api.deepsearch.com/v1/compute?input=DocumentSearch(["news"],["economy"],"딥서치")

```

# 문서데이터

딥서치에서 쿼리로 조회가능한 문서데이터를 설명합니다.

## 문서 데이터

DeepSearch를 통하여, 30년 이상 수집된 다양한 금융 문서(뉴스, 공시, 증권사리포트, IR, 알파)를 손쉽게 검색할 수 있습니다.

문서 데이터의 검색은 기업에 대한 문서 뿐 아니라, 각종 키워드에 대한 문서 검색을 지원하며, 보다 심화검색을 원하시는 경우 DocumentSearch 함수를 활용하거나 딥서치 문서 검색 메뉴를 이용하면 더욱 깊이 있는 검색을 수행할 수 있습니다.

딥서치의 재무계정은 "나이스/재무제표/IFRS/연결/제조업/재무상태표/자산"과 같은 형식으로 저장되어있습니다. 따라서, **자산**으로 검색을 하는 경우, "나이스/재무제표/IFRS/연결/제조업/재무상태표/**자산**" 이 매칭되어 자산 재무계정을 조회합니다. 하지만, 수많은 기업의 재무계정은 일원화되기 어려우며, 각 업종별, 회계기준별, 연결/별도별로 구분되어 있습니다.

| **구분예시** | **데이터 예시**                                              |
| -------- | ------------------------------------------------------- |
| 회계기준     | IFRS / GAAP                                             |
| 연결재무제표여부 | 연결 / 별도\|개별                                             |
| 업종구분     | 표준 / 제조업 / 은행업 / 증권업 / 생명보험업 / 손해보험업 / 신용금고업  / 종합금융업 등 |
| 재무제표 종류  | 손익계산서 / 재무상태표 / 현금흐름표                                   |

재무계정은 회계기준별, 연결재무제표여부별, 업종별, 재무제표 종류별로 다르게 정의되어있습니다. 따라서, 사용 빈도가 높은 정보를 우선순위 조회되도록 구성 되어있습니다. 현재, 딥서치내 재무계정체계의 우선순위는 아래와 같습니다.

![](https://2002947409-files.gitbook.io/~/files/v0/b/gitbook-legacy-files/o/assets%2F-LPJrnQiLiz9bWVBvx6Q%2F-McSabBMIjg6bTNvTKWg%2F-McTLksirPBFl40iDR_9%2Fimage.png?alt=media\&token=ce7ba3fa-7376-4423-aa9c-a4d5208cb17b)

현재, "자산" 이라고 검색하는 경우 첫번째 우선순위인 "**IFRS/연결/표준**" 재무제표내에서 자산계정을 탐색하며, 만약 첫번째우선순위인 "**IFRS/연결/표준**" 재무제표내에서 값이 존재하지 않은 경우, 두번째 우선순위인 "**IFRS/연결/제조업**" 내 재무계정을 탐색합니다. 데이터가 존재하지 않는다면, 순차적으로 우선순위가 마지막인 41번째의 "**GAAP/개별|별도/기타금융업**" 내 재무계정을 탐색합니다.

### 우선순위 탐색 예시

| 제조업 자산      | 제조업 업종에서 가장 우선순위가 높은 **IFRS/연결/제조업** 에서 검색됨.             |
| GAAP 제조업 자산 | GAAP 회계기준이면서 제조업종 중에서 우선순위가 가장 높은 **GAAP/연결/제조업** 에서 검색됨 |
| 신용카드업 자산    | 신용카드업종 중에서 우선순위가 가장높은 **IFRS/연결/신용카드업** 에서 검색됨           |

# 기본적인 데이터 조회 방법

딥서치 데이터를 조회할 수 있는 방법에 대해서 설명합니다.

DeepSearch API 는 방대한 이종 데이터의 조회, 연산을 지원하며, 이를 위하여 아래 3가지의 형태로 사용자는 데이터를 처리할 수 있습니다.

1. 쿼리를 통한 데이터 조회&#x20;
2. API 함수를 통한 데이터 조회
3. 조회된 데이터를 연산

모든 처리는 compute API 를 통하며, {입력} 부분에 쿼리 혹은 API 를 입력합니다.&#x20;

```
api.deepsearch.com/v1/compute?input={입력}

// 쿼리형태의 데이터조회 URL

https://api.deepsearch.com/v1/compute?input=삼성전자 매출액
https://api.deepsearch.com/v1/compute?input=삼성전자 매출액 2010-2020


// api형태의 데이터조회 URL

https://api.deepsearch.com/v1/compute?input=GetCompanyHistory(삼성전자)
https://api.deepsearch.com/v1/compute?input=GetCompanyHistory(KRX:005930,KRX:000020)
```

## 쿼리 형태의 데이터 조회&#x20;

간단한 쿼리 형태로 데이터를 조회 합니다.&#x20;

```
삼성전자 매출액
삼성전자 매출액 2018
삼성전자 매출액 2010-2018
삼성전자 주가
삼성전자 주가 2019-3-5
삼성전자 주가 2019-1-1-2019-12-31
```

쿼리는 자산이름, 속성(property), 기간으로 구성되며, 자산이름, 속성, 기간은 다수개 입력이 가능합니다.&#x20;

```
삼성전자 LG전자 주가 거래량 2019-3-5 2019-3-6
```

쿼리 입력의 예시는 아래와 같습니다.

```
api.deepsearch.com/v1/compute?input=삼성전자 LG전자 주가 거래량 2019-3-5 2019-3-6
```

쿼리 형태의 데이터 추출이 가능한 전체 속성 리스트는 다음의 페이지를 참조하십시오.

{% endcontent-ref %}

entity - property - date range 형태로 조회가 용이하지 않은 데이터는 별도 API 함수를 생성하여 조회하고 있습니다. 기업분석 페이지의 컨센서스, 주주, 분야별 매출 등이 이에 해당합니다.

# 데이터

### Q. 국내 모든 법인에 대해 조회가 가능할까요?

국내 자영업 혹은 영세한 일부 기업들을 제외한 모든 법인은 조회가 가능해요. 국내 법인이라면 딥서치에서 정보 조회가 가능하다고 이해해주시면 되고, 다만 공시의 의무 여부에 따라 혹은 확보된 데이터에 따라 보여지는 기업들의 정보는 다른 점 참고 부탁드려요.

* 외감 기업 : 약 3만 3천 개
* 비외감 기업 : 약 130만 개

### Q. 정보에 대한 출처는 어디인가요?

재무제표 정보를 포함하여 전반적으로 기업에 대한 정보의 출처는 나이스평가정보로부터 제공받고 있어요.

### Q. 연결 재무제표 다운로드가 안돼요.

기업마다 공시하고 있는 재무제표의 유형은 다르게 되어있어요. 개별 재무제표 조회가 되고 있는 기업이 반드시 연결 재무제표 공시는 안 할 수 있기 때문에 없다고 해서 문제가 되는 것은 아닌 점 참고 부탁드려요.

관련해서 문제가 없는지 확인 요청은 딥서치 고객센터로 문의 주세요.

### Q. 트렌딩 토픽 이슈기업은 어떻게 추출하나요?&#x20;

딥서치 자체적으로 보유한 ML기술을 통해 해당일에 발생한 뉴스의 수, 언급된 키워드의 빈도를 종합적으로 고려하여 노이즈를 제거하고 주요 토픽을 추출합니다.

### Q. 외감기업, 비외감기업이 무엇인지 알려주세요 <a href="#title-text" id="title-text"></a>

외감기업은 자산총액이 120억원이 넘는 등의 조건을 만족하여 “주식회사의 외부감사에 관한 법률”(외감법)에 따라 회계법인으로 부터 의무적으로 회계감사를 받는 기업을 의미 합니다.

외감기업은 회계감사를 받은 후 재무제표가 포함된 감사보고서를 금융감독원 전자공시시스템([![](https://dart.fss.or.kr/favicon.ico)전자공시시스템](https://dart.fss.or.kr/))에 공시하게 됩니다. 따라서 매 사업연도 말 감사받은 재무제표를 확인할 수 있습니다.

참고로 상장법인은 모두 외감기업이며, 사업연도말 기준 감사받은 재무제표외 분기와 반기마다 검토받은 재무제표를 공시합니다.

비외감기업은 외감기업이 아닌 기업으로 감사받은 재무제표를 공시할 의무가 없으나, 대출을 받기 위한 신용평가를 위해 임의감사를 받아 재무제표를 작성하여 신용평가기관 또는 은행에 제출하기도 합니다. 딥서치의 비외감기업 재무제표는 나이스평가정보로부터 제공받고 있습니다.

자산총액이 120억이 넘는 회사로, 회계법인으로부터 의무적으로 회계감사를 받아야 합니다. 의무적으로 회계감사를 받도록 하는 이유는 회사의 투명성과 신뢰성을 높여 기업의 사회적 책임을 강조하고, 투자자들의 피해를 막기 위해서 입니다

### Q. 주가, 거래량은 실시간으로 업데이트 되나요? <a href="#title-text" id="title-text"></a>

네, 주가와 거래량은 코스콤으로 데이터를 받아 딥서치에서 실시간으로 업데이트 됩니다. (다만, 트래픽 증가 등의 사유로 지연이 발생할 수 있습니다)

## Q. 재무데이터 업데이트는 언제 되나요? <a href="#title-text" id="title-text"></a>

| **상장기업**       | 상장기업은 매 분기말 재무제표를 공시하며, 분기말로 부터 2\~3개월 뒤에는 상장기업 대부분의 재무데이터가 업데이트 됩니다.                          |

## Q. 재무정보가 없는 데이터가 있어요 <a href="#title-text" id="title-text"></a>

재무제표를 공시할 의무가 없는 비외감법인이 임의감사를 받지 않거나, 재무제표를 신용평가기관 등에 제출하지 않은 경우 재무자료가 없을 수 있습니다.

## Q. PER와 PBR의 계산기준이 어떻게되나요? <a href="#title-text" id="title-text"></a>

* **PER**
  * PER = 시가총액 / 당기순이익 으로 계산됩니다.
  * 매년 5월 1일을 기준으로 **최신연도의 당기순이익 금액**으로 업데이트됩니다.
  * 예 : 2021년 5월 1일 기준의 당기순이익은 2020년 당기순이익 금액으로 업데이트
* **PBR**
  * PBR = 시가총액 / 자산 으로 계산됩니다.
  * 매년 5월 1일을 기준으로 **최신연도의 자산 금액**으로 업데이트됩니다.
  * 예 : 2021년 5월 1일 기준의 자산은 2020년 자산 금액으로 업데이트

## Q. 재무제표는 어떤 기준으로 제공되나요? <a href="#title-text" id="title-text"></a>

재무제표 각 항목별로 아래와 같은 기준으로 제공하고 있습니다.

* 기준일 : 상장기업은 연, 분반기 기준으로, 비상장기업은 연간기준으로 제공합니다. (비상장기업이더라도 분반기 재무제표를 공시할 경우 분반기 재무제표를 제공해드립니다)
* 연결/별도 : 연결과 별도재무제표 모두 제공하고 있습니다.
* 회계기준 : IFRS와 GAAP기준으로 모두 제공하고 있습니다.
